StudyMate AI Android starter project

This ZIP contains Android Studio source code, not a precompiled APK.
The current version is a working offline UI prototype. It can prepare study prompts
for copying into ChatGPT, but it does not yet call an AI API directly.

Build an APK:
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. Android Studio > Open, and choose the extracted StudyMateAI folder.
4. Wait for Gradle sync to finish.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show the generated APK location.

To make AI answers happen inside the app, add a secure backend/API integration.
Do not put a private AI API key directly inside an APK.
